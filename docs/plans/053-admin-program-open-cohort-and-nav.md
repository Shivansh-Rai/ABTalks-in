# 053 — Admin program: code-less cohorts + header re-layout

## 1. Goal

Let an admin create a cohort in one of two enrollment modes — **join code
required** (today's behavior) or **open, no code** (anyone signed in can apply
straight from `/program/apply`) — and rework the `/admin/program` header: cohort
switcher on top with **Create new cohort** at the right end of that row, and the
`Overview / Members / Projects / Interviews / Recruiters / Content` tab bar below it.

---

## 2. Current behavior

### Data model — `prisma/schema.prisma:571-583`

```prisma
model ProgramCohort {
  id                 String              @id @default(cuid())
  name               String
  joinCode           String              @unique
  startsAt           DateTime            // IST Day-1 anchor
  endsAt             DateTime
  capacity           Int                 @default(100)
  status             ProgramCohortStatus @default(DRAFT)
  resultsPublishedAt DateTime?
  createdAt          DateTime            @default(now())
  ...
}
```

Every cohort has a mandatory unique 8-char `joinCode`
(`src/lib/program-auth.ts:10-21`). There is no way to express "no code needed".

### Applicant flow — `src/features/program/entry.ts:174-248`

`getEntryState(userId, joinCode?)` resolution order: enrolled → waitlisted →
existing `APPLIED` membership → **join code**. The last branch is
`entry.ts:233-247`:

```ts
const rawCode = joinCode?.trim();
if (!rawCode) return { screen: "need_code" };

const cohort = await getCohortByJoinCode(rawCode);
if (!cohort) return { screen: "invalid_code" };
if (cohort.status !== "ENROLLING") return { screen: "closed", ... };
return { screen: "form", cohortName, joinCode: cohort.joinCode, existingProfile: null };
```

So a code is **always** required to reach the apply form.
`/program/apply` (`src/app/program/apply/page.tsx:48-68`) renders `JoinCodeGate`
for `need_code` / `invalid_code`; the form screen renders
`<ApplyForm joinCode={state.joinCode} />`, and `ApplyForm` posts that same code
back through `applyToProgramAction` → `createApplication`
(`src/features/program/entry.ts:250-314`), which re-resolves the cohort by code
server-side. With `isProgramEntryBypassEnabled()` permanently `true`
(`src/lib/feature-flags.ts:21-23`), applying enrolls or waitlists immediately.

### Admin header — `src/app/admin/program/layout.tsx:15-32`

Current DOM order inside `space-y-6`:

1. `<ProgramAdminNav />` — tab bar, `border-b pb-4`
   (`src/components/program/program-admin-nav.tsx:22-45`)
2. `<ProgramCohortSwitcher />` — `Cohort` label + `<select>` + mono join code
   (`src/components/program/program-cohort-switcher.tsx:42-74`)
3. `{children}`

Both are client components (`useSearchParams`) wrapped in `Suspense`. Cohort
selection is URL state: `?cohortId=…`; the nav preserves it in every tab href.

### Create-cohort control — `src/components/program/program-cohort-panel.tsx:167-183`

The **Create new cohort** button lives inside the cohort settings card on the
Overview page, next to the `Cohort settings` heading, and toggles local
`createMode` state (`panel:53`, `startCreate:152-155`, `cancelCreate:157-165`).
It is invisible from Members / Projects / Interviews / Recruiters / Content.

### What does not exist

- No enrollment-mode concept — every cohort is code-gated.
- No way to reach the apply form without a code.
- No create-cohort entry point outside the Overview tab.

### Decisions taken

| Question | Decision |
| --- | --- |
| How to model "no code" | New `requiresJoinCode Boolean @default(true)`. **`joinCode` stays non-null + unique for every cohort**, including open ones — no nullable unique column, no backfill, and flipping open → coded later needs no code generation. |
| Which cohort an un-coded applicant lands in | Newest `ENROLLING` cohort with `requiresJoinCode = false`, by `createdAt desc`. Deterministic; surfaced as helper copy in the admin form. |
| Can an existing cohort switch modes | Yes — the same radio is editable in update mode. Flipping to open does not change or clear the join code. |
| Coded-cohort applicants when an open cohort exists | `/program/apply` shows the open cohort's form, plus a **"Have a join code?"** link to `/program/apply?gate=1` which forces the join-code gate. Without this, an open cohort would lock every other cohort's applicants out of the gate. |
| Create-button placement | Right end of the switcher row, rendered by `ProgramCohortSwitcher` (it already reads `searchParams`, so it can preserve `cohortId`). Navigates to `?create=1`; the panel's create mode becomes URL-derived instead of local state. |

/**
 * Newest ENROLLING cohort that does not require a join code.
 * When several open cohorts are ENROLLING, the most recently created one wins.

export async function getOpenEnrollmentCohort() {
  return prisma.programCohort.findFirst({
    where: { status: "ENROLLING", requiresJoinCode: false },
    orderBy: { createdAt: "desc" },
    select: { id: true, name: true, status: true, joinCode: true },
  });
}
