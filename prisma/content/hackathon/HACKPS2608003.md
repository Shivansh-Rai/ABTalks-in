Don't build an AI that writes posts. Build an AI that wants to post.

# The Situation

Thousands of AI-generated posts land on **LinkedIn** and **X** every day, and almost every one of them exists because a human typed a prompt first.

The model is a very good pen.

A person is still holding it.

Build the thing that doesn't need the prompt.

Create an AI persona with:

- Its own interests
- Its own editorial taste
- Its own memory

The agent should:

- Discover what is worth talking about.
- Decide whether it is actually worth publishing.
- Write in a voice that remains consistently its own.
- Continue doing the same tomorrow without any human prompting.

Your persona can be anything, for example:

- An AI security researcher
- A climate analyst
- A film critic with strong opinions
- Or any original personality you invent

Once initialized, the agent should continue running autonomously.

---

# Ship at Minimum

Your solution must include the following capabilities:

## Topic Discovery

The agent independently discovers topics from the web or another live information source.

---

## Editorial Decision

Not every discovered topic deserves publishing.

Your agent should demonstrate editorial judgment by **declining** some topics instead of posting everything it finds.

---

## Consistent Persona

Maintain one identifiable personality with:

- A consistent writing style
- Stable interests
- Recognizable opinions

The persona should remain coherent across all published posts.

---

## Memory

The agent should remember what it has previously published.

For example:

- Post 9 should know what Post 2 discussed.
- Previously covered ideas should not be repeated unnecessarily.

---

## Autonomous Publishing Cadence

The agent should publish on its own schedule rather than generating everything at once.

Judging includes an unattended observation window of approximately **48 hours** after submission.

Your solution should therefore produce a sustained stream of posts throughout that period.

> Simulated publishing is completely acceptable. The agent does **not** need to publish to a real social media platform, but new posts must appear automatically through the feed endpoint without additional human input.

---

## Publishing Rationale

Every published post must include:

- Why this topic was selected
- Why it is relevant now
- Where the information originated

This information should be returned through the **`rationale`** and **`sources`** fields of the feed response.

---

# What We're Looking At

Evaluation focuses on:

- Whether the agent **continues operating without human intervention**.
- Whether the persona feels genuinely unique rather than cosmetic.
- Whether memory prevents repetitive content over time.
- Whether the agent can justify its editorial decisions.
- Whether the resulting feed is interesting enough that someone would genuinely follow it.

---

# Success Looks Like This

By the end of the hackathon, your agent should be able to:

- Discover its own topics
- Decide whether each topic deserves publishing
- Maintain a consistent persona
- Remember previous posts
- Continue publishing without additional human prompts

---

# Out of Scope

The following are **not required**:

- Posting to real social media platforms
- Multi-platform publishing
- Images or videos
- Engagement analytics
- Trend detection
- Multi-agent orchestration
- Human intervention after initialization

> After initialization, the agent should operate completely autonomously.

---

# API Requirements

Your submission must expose **two HTTP endpoints**:

## Initialize Agent

Called **only once** to create and configure the autonomous creator.

```http
POST /api/agent/init
```

### Request

```json
{
  "persona": {
    "name": "...",
    "beat": "AI security",
    "voice": "...",
    "goals": ["..."]
  }
}
```

### Response

```json
{
  "agentId": "abc-123"
}
```

---

## Retrieve Feed

After initialization, this is the **only endpoint** the evaluator will call.

```http
GET /api/agent/feed?agentId=abc-123
```

### Response

```json
{
  "posts": [
    {
      "id": "p7",
      "createdAt": "...",
      "platform": "linkedin",
      "text": "...",
      "rationale": "why this topic, now, over the alternatives",
      "sources": [
        "https://..."
      ]
    }
  ]
}
```

---

# Submission Rule

The endpoint separation is intentional.

- The evaluator initializes your agent **once**.
- No further instructions will be sent.
- The evaluator only checks the feed endpoint.

If new posts continue appearing over time, they must have been generated **entirely by the autonomous agent**.
