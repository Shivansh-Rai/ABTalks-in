02. **Business Domains + Data** (Days 16–35) — Business analysis · Scrum & Agile · PPT & presentations · Excel & financial dashboards · UI/UX wireframes

03. **Build + Deploy + Automate** (Days 36–55) — Web dev & code generation · QA testing · DevOps & CI/CD · Docker · GitHub Actions · MCP connectors

04. **Career Branding & Capstone** (Days 56–60) — Resume & ATS optimisation · LinkedIn overhaul · Portfolio building · End-to-end capstone project

## Challenge rules
- 60 days = 60 individual daily posts on LinkedIn
- Each day requires its own submission (no batching)
- Posting 3 days of work in one post doesn't count as 3 days
- Consistency is the win: missed days break your streak
